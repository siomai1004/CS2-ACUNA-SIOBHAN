# Electricity Bill Calculator


## Description
This program calculates the electricity bill based on the user's inputs.

## Version 1 - Original code without input validation
- Input: Accepts the customer's name and the previous and current meter reading.
- Process: Calculates and displays the customer's name, consumption, and total bill.
- Output: Customer's name, consumption, and total bill.
- Does not include input validation

## Version 2 - Code with input validation
- Input: Accepts the customer's name if there is an input and the previous reading with a minimum of 0 and the  current meter reading that cannot be lower than the previous reading.
- Process: Calculates and displays the customer's name, consumption, and total bill
- Output: Customer's name, consumption, and total bill.
- Includes input validation.
